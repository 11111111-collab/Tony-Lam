# 貼到 Cargo 用的程式碼

把這個作品集搬到 cargo.site 用的六段程式碼。每一段對應 Cargo 上的一個頁面。

> **我沒辦法查證 Cargo 編輯器目前的實際限制**——這個環境的網路政策擋掉
> cargo.site（`CONNECT tunnel failed, 403`）。下面關於 Cargo 介面的說法
> 是既有認知，不是查證過的。貼的時候如果對不上，把你實際看到的畫面告訴我。

## 檔案

```
00-網站樣式.css     全站樣式，貼進 Cargo 的自訂 CSS，一次就好
1-Home.html         ┐
2-Biography.html    │
3-Works.html        │ 六段 HTML，各貼進對應頁面的程式碼區塊
4-沉澱的記憶.html    │
5-聲音的重量.html    │
6-Contact.html      ┘
standalone/         同樣六段，但樣式直接內嵌在裡面。
                    找不到「自訂 CSS」欄位時改用這個資料夾，
                    六頁各自獨立，不必貼 00-網站樣式.css。
```

## 步驟

1. **貼樣式**：把 `00-網站樣式.css` 整份貼進 Cargo 的自訂 CSS 欄位。
2. **建六個頁面**，把對應的 `.html` 貼進各頁的程式碼區塊。
3. **改導覽列連結**：每段開頭的註解列出該頁要換掉的佔位字串，例如
   `#換成你的-biography-頁面網址`，換成你 Cargo 上那一頁的實際網址。
4. **放圖片**：灰色虛線框就是圖片欄位，框上寫了該放哪張、什麼比例。
   把圖片放進那個 `<div>`／`<a>` 標籤**裡面**，虛線框會自動消失。
   框的比例是鎖住的，換圖不會跑版。

## 為什麼不能直接貼原本的 HTML

原本六個檔案是完整的 HTML 文件，各有自己的 `<html><head><body>`。
Cargo 是它自己輸出整份文件，所以有三個地方會壞：`<head>` 不是你的、
Cargo 的 CSS 會跟同名類別打架、而整套縮放系統原本靠
`body { container-type: inline-size }`——那個 `body` 你改不到。

這裡的版本做了三件事解決：

1. **全部包進命名空間**：所有類別加上 `csl-` 前綴，所有選擇器包在
   `.csl-site` 底下，不會跟 Cargo 的樣式互相污染。
2. **縮放基準換成容器**：`container-type` 改掛在自己的外層 `div`，
   `--vw` 量的是「這個容器有多寬」，不再需要動 `body`。
3. **斷點從 `@media` 改成 `@container`**：版面跟著它被放進去的欄位寬度變，
   不再跟瀏覽器視窗綁定。所以就算 Cargo 把它放在一個窄欄裡，
   也會自動切成該有的版型。

## 驗證數據

**一、與正式站比對。** 把六段程式碼放進一個刻意作對的假宿主頁
（自己的 Georgia 字體、行高 2.1、`box-sizing: content-box`、
還故意定義了 `.section` / `.brand` / `.work-card` 等同名類別），
再跟 `art-site/` 的正式頁面逐元件比 x / y / 寬 / 高：

> 三個斷點共 **201 項，全部落在 2px 以內**。

**二、容器查詢真的有效。** 在**同一個 1400px 視窗**裡並排三個不同寬度的欄位：

| 欄寬 | 站名字級 | 選單位置 | 實際套用 |
|---|---|---|---|
| 393px | 24.723px | 15, 82 | 手機版 |
| 771px | 28.9868px | 470, 29 | 平板版 |
| 204px | 24.723px | 8, 42 | 手機版（再等比縮小） |

768px 那欄量到的 `470, 29` 與正式站平板版的實測值一致。

**三、圖片欄位空著不影響版面。** 五個頁面的主圖框，有圖與空欄位兩種狀態
量到的位置與尺寸完全相同。

## 已知限制

- 字體 `aether` / `alfabet` 連向 Wix 的 CDN。Cargo 若擋外部字體，
  英文會回退到 Helvetica／Arial，中文不受影響（本來就走系統字體）。
- `@container` 需要較新的瀏覽器（2023 年起的版本）。太舊的瀏覽器會
  一律套用桌機版，不會崩，但窄螢幕上會過小。
- 原站既有的版面問題（標題換行重疊、Works 頁手機兩欄字太小等）
  在這裡一併保留，沒有擅自修改。詳見上一層的 `../README.md`。
